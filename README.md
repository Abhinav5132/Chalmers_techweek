# Unitree G1 Humanoid Skill Orchestrator (SKF Hackathon)

See the full architectural specification in [SYSTEM_DESIGN.md](file:///mnt/idfk/programming_stuff/SKF_Hackathon/SYSTEM_DESIGN.md).

## Quickstart
Run `git clone https://github.com/unitreerobotics/unitree_mujoco.git` in the project root to download the unitree g1 model. 

To run the simulation:
```bash
python -m mujoco.viewer
```
and then drag and drop `unitree_mujoco/unitree_robots/g1/g1_29dof.xml` into the viewer to view the robot.
